Annict作品データ同期

1回につき最大5ページ、1ページ50作品を取得します。取得した候補は非公開で保存し、管理者が内容を確認してから公開します。

Annict APIが提供する作品画像は権利者の許諾を意味しないため取得しません。日本作品・対象形式・成人向けでないこと・情報の正確性を確認してから公開してください。

SupabaseのEdge Function Secretsへ ANNICT_ACCESS_TOKEN を登録してください。トークンをこの画面や公開コードへ入力しないでください。

Wikidata自動作品収録

  
Wikidataから日本由来のアニメ作品候補を定期取得します。自動処理は毎日11:30（日本時間）に最大50件を順次確認します。新規レコードは非公開で登録し、既存作品の編集内容・公開状態は上書きしません。必要な場合は下のボタンから手動実行できます。

  
作品名・形式・公開年・話数などの構造化情報のみを取得します。画像・バナー・あらすじ本文は取得しません。自動登録後も「作品候補の審査」で対象作品かどうかを確認してから公開してください。

  

  

  

  

  
Wikidataのライセンス · Query Serviceの利用上の注意






  
放送クール情報の一括補完（AniList）

  
MyAnimeList IDで作品を照合し、AniListの公式APIが返すseason・seasonYear・startDateを取得します。作品名検索ではなく外部IDで一致させるため、別作品への誤紐付けを避けます。

  
TV・短編TV・ONAの公開作品のみ対象です。映画・OVAはクール分類に含めません。まずプレビューで照合結果を確認し、その後に同期してください。外部IDがない作品やAniListにクール情報がない作品は変更しません。

Wikidataエピソード自動収録

  
公開済みのWikidata作品を対象に、エピソード名・話数表記・公開日を照合して取得します。取得したエピソードは必ず非公開で登録し、審査後に個別公開します。

  
Wikidataに登録されたエピソードだけが対象です。未登録・不完全な作品もあります。既存のAnnict等のエピソードがある作品は混在を避けるため自動取込をスキップします。既存レコードや公開状態は上書きしません。

  

  

  

  

  
Wikidataのライセンス · SPARQLクエリ例





作品詳細データの同期
Annictの作品IDを指定します。エピソード・キャスト・スタッフを各1ページずつ取得し、次ページがある場合はカーソルを更新して続行できます。


















作品画像の同期（Wikimedia Commons）


公開済み作品の名称をWikimedia Commonsで照合し、CC0・パブリックドメイン・CC BY・CC BY-SAのライセンス情報を確認できた画像だけを登録します。


公式ポスターが見つかるとは限りません。画像名・作品名が十分に一致し、画像の縦横比とライセンスを確認できた場合だけ登録します。条件に合わない場合はANIXIAの共通プレースホルダーを表示します。

人物・キャラクター等の名称総合検査

  
人物・声優・スタッフ、キャラクター、制作会社、制作組織の名称と読み仮名を全件検査します。ひらがな表記、英字表記、日本語名・読み仮名の欠落などを確認候補として抽出します。

  
ひらがな表記が正式名称の人物・キャラクター・制作会社も存在します。自動で漢字へ変換したり、レコードを削除したりしません。公式プロフィール・公式クレジット等の根拠を確認してから修正してください。
