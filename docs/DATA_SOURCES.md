確認できた条件：
- Wikidataの構造化データはCC0で提供される。
- 出典表示は必須ではないが、Wikidataをデータの出所として記載することが推奨されている。

## 3. Annict APIの条件

公式規約は2026-10-25制定、2026-11-25施行予定。

公式規約： https://annict.com/terms/api  
REST API作品情報： https://developers.annict.com/docs/rest-api/v1/works  
レート制限ヘルプ： https://wikino.app/s/annict/pages/419

確認できた条件：
- API利用料金は無料。規約を守る限り、広告・アフィリエイト等を含む商用利用も可能。
- 作品情報は、アプリケーションの提供に必要な範囲で保存・キャッシュでき、保存期間・件数に上限はない。
- 取得データを、第三者がまとめて取り出せるデータセット・ファイル・独自APIとして再配布してはならない。
- Webアプリケーションでは、開発者側で検索し、画面表示に必要な分だけを返す形が求められる。
- Annict APIの作品画像は権利者の著作物であり、Annictは画像利用を許諾する立場にない。ANIXIAの同期処理では画像URLを取得・保存しない。
- Annictの利用者情報は、作品情報とは別の条件で扱う。ANIXIAの共用トークンでは作品情報だけを取得し、ユーザー情報は取得しない。
- Annictの名称・ロゴは出典表示に利用できるが、公式・提携サービスと誤認させる表示は禁止。

現時点では新規規約の施行前であり、ANIXIAのAnnictソースは `pending` / 無効のままにする。施行日以降に改めて規約を読み、権利確認後に有効化する。

## 4. レート制限と同期方法

### Wikidata（稼働中）

- Supabase Edge Function：`sync-wikidata-catalog`。
- 全作品カタログ同期：Edge Function `sync-wikidata-catalog`。Supabase Cron `anixia-wikidata-catalog-sync` が毎日02:30 UTC（日本時間11:30）に最大50件を取得し、候補を自動収録する。公開状態は自動変更しない。
- シーズン作品同期：Edge Function `sync-seasonal-anime`。Supabase Cron `anixia-seasonal-anime-sync` が毎日03:35 UTC（日本時間12:35）に実行する。作品の公開状態はDB側の管理者審査ルールに従う。
- HTTP 429では `Retry-After` を尊重し、5xxでは間隔を空けて再試行する。
- 取得対象は日本由来（country of origin = Japan）で、1963年以降の対象クラスに属する作品。作品名・形式・年・話数などの構造化情報のみを扱う。
- 日本語タイトルがあり、対象形式（TV・映画・OVA・ONA等）と日本由来・1963年以降の条件を満たす作品を候補として収録する。
- 作品の公開は自動確定しない。管理者審査を通過した作品のみ公開する。日本語タイトルがない作品や形式が不明な作品は候補のまま保留する。
- Wikidataの明示的な除外分類を同期時に確認するが、分類が欠落・誤りの場合を完全には検出できない。出典IDを保持し、重複候補検査を継続する。
- 2026-11-17時点の同期カーソルは20。手動実行2回の成功を確認済み。Cronジョブは有効だが、初回の定期実行ログは未確認。

### Annict（未有効化）

Annictの大量取得時は、最新の公式条件を再確認した上で、逐次取得・ページ分割・429待機を行う。現行同期機能は1回最大5ページ（最大250作品）、逐次リクエスト、ページ間隔約1.1秒、429の `Retry-After` 対応。画像フィールドは取得せず、新規作品は非公開で保存する。利用規約施行後の確認が完了するまでソースを無効のままにする。

## 5. 管理者審査・公開条件

- 日本由来（Wikidata P495 = Japan）で1963年以降の対象クラスに属する作品を自動収録候補にする。
- 日本語タイトルがあり、形式がTV・映画・OVA・ONA等の許可リストに含まれるかを機械判定する。
- Wikidataの明示的な除外ジャンルが確認できる作品は候補から除外する。
- 収録候補の取得と公開確定を分離する。作品・エピソードともに管理者審査を通過するまで公開しない。
- 同一Wikidata IDは `source, source_id` の一意制約で重複登録を防止し、MyAnimeList IDも照合する。
- Wikidataの分類は欠落・誤りの可能性があるため、自動判定だけで対象作品の完全性を保証しない。
