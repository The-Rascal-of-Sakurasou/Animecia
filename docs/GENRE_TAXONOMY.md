# ANIXIA ジャンル分類方針

確認日：2026-11-17

## 分類の考え方

- **ジャンル**：作品の物語・表現の中心となる大分類。
- **タグ**：舞台、設定、モチーフ、題材、対象層など、複数作品を横断する特徴。
- **形式**：TV、映画、OVA、ONA、SPECIALなど。ジャンルとは別の属性として管理する。

「学園」「異世界」「転生」「魔法」「アイドル」「タイムトラベル」などは、作品全体のジャンルと混同しないよう、原則としてタグ候補にする。

## 初期ジャンル

| 英語名 | 日本語名 | 分類の目安 |
|---|---|---|
| Action | アクション | 動きのある展開や対決 |
| Adventure | アドベンチャー | 旅・探索・未知への挑戦 |
| Comedy | コメディ | 笑いやユーモア |
| Drama | ドラマ | 人間関係・葛藤・社会的出来事 |
| Fantasy | ファンタジー | 魔法・架空世界 |
| Science Fiction | SF | 科学技術・未来・宇宙 |
| Romance | 恋愛 | 恋愛関係・感情の変化 |
| Slice of Life | 日常 | 日常生活・身近な出来事 |
| Mystery | ミステリー | 謎や真相の解明 |
| Suspense | サスペンス | 緊張感・危機・先の読めない展開 |
| Horror | ホラー | 恐怖や不安 |
| Sports | スポーツ | スポーツ・競技 |
| Music | 音楽 | 音楽・演奏・歌唱 |
| Historical | 歴史 | 過去の時代・歴史的背景 |
| War | 戦争 | 戦争・紛争 |
| Mecha | ロボット | ロボット・搭乗型メカ |
| Psychological | 心理 | 心理・内面的な葛藤 |
| Supernatural | 超自然 | 超常現象・人知を超えた存在 |

この初期分類はANIXIA独自の編集分類であり、外部APIの分類をそのまま複製したものではない。複数ジャンルの付与は許容するが、作品ごとに根拠を確認する。タグの追加・統合・改名は、既存作品への付与状況と検索への影響を確認してから行う。
