# ANIXIA: Animecia + AQW 統合ロードマップ

## 方針
ANIXIAはAnimecia（アニメ総合DB）とAQW（アニメクイズ）の成果を継承し、検索・記録・評価・発見・クイズを統合する。既存Animecia/AQWは無断変更せず、ANIXIA側で独立して統合する。

## 現状（2026-11-18確認）
- anime: 383作品
- 作品、人物、キャラクター、スタッフ、スタジオ、ジャンル、タグ、外部ID、シリーズ、レビュー、評価、視聴記録、お気に入り、クイズ、実績、ユーザー等のテーブルが存在。
- quizzes / quiz_questions / quiz_choices / quiz_attemptsは存在するが確認時点の件数はすべて0。
- watch_entries / reviews / ratingsも確認時点で0。
- テーブルの存在だけではUIやRLSの正常稼働を意味しないため個別検証する。

## Animecia継承：データベースとライブラリ
- 自動作品収集と重複防止（外部ID、タイトル、別名等）
- 日本語・英語・読み仮名検索
- 詳細情報、スタッフ、キャスト、制作会社、ジャンル、関連作品
- ライセンス・出典に基づくタイトル画像
- 視聴記録、評価、レビュー、お気に入り
- ランキング、絞り込み、推薦

## AQW継承：クイズと参加体験
- クイズ一覧、カテゴリ・難易度・形式別探索
- 選択式クイズ、採点、解説、結果画面
- 挑戦履歴、自己ベスト、ランキング
- 作品DBとクイズの相互リンク
- 実績・進捗（既存テーブル活用）
- 将来のイベント・対戦は公平性、安全性、コストを検討してから

## 優先実装順
1. DB/API/RLSとUIの現状監査、テスト基準作成
2. 自動収集・照合・重複防止の堅牢化
3. 画像の許諾・ライセンス基準と出典UI
4. クイズ作成／表示／回答／採点／解説を一貫実装
5. ライブラリ・評価・レビュー・実績の検証と統合
6. ランキング・推薦・コミュニティの連携
7. PC・スマホ・タブレット、アクセシビリティ、SEO、性能、エラー対応の総合試験

## 自動収集・画像方針
- API利用条件・ライセンスを確認し許可範囲で利用する。
- 画像の出典、ライセンス、URL、取得日時を記録する。
- 照合が曖昧な場合は自動上書きせずレビュー対象とする。
- 手動確認済みデータを同期が無断上書きしない。
- API障害時はバックオフ・上限付き再試行・ログを設ける。
- AniListは利用条件確認が必要なため承認前の一括取得に使用しない。

## セキュリティ・品質
- 個人情報を最小化し、ユーザーデータをRLSで分離。
- クイズ正答データを公開クライアントから取得できないようにする。
- privileged keysをフロントエンドに出さない。
- 同期処理は認証・権限・レート制限を設ける。
- 実装後はDB・テスト・画面動作を検証し、検証済みのみ完了とする。

## 成功指標
- 重複・誤照合を抑制
- 正確な作品情報・画像・出典表示
- クイズ出題から記録まで一連で動作
- 個人データアクセス制御を検証
- 主要操作がPC・スマホ・タブレットで動作
