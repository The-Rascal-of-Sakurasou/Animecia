# ANIXIA 自動カタログ収録システム

更新日：2026-11-18

## 目的

ANIXIAの作品・人物・キャラクター・制作会社・ジャンル等の構造化データを、利用条件を確認したデータソースから定期的に収集し、重複を避けてSupabaseへ追加する。

「インターネット上の全情報を無条件に取り込む」仕組みではない。情報源に存在しない情報、権利を確認できない文章・画像、作品同一性が曖昧な関係は自動生成しない。

## 自動実行スケジュール

時刻はUTC。括弧内は日本時間。

| 処理 | 実行時刻 | 内容 |
|---|---|---|
| 作品候補収集 | 毎日 02:30（11:30） | Wikidataから候補を取得し、非公開候補として保存 |
| 作品情報の拡充 | 毎日 03:15（12:15） | 公開済み作品の空欄情報を補完 |
| エピソード候補 | 毎週日曜 04:00（13:00） | Wikidataの各話構造を検索し、取得できたものを候補化 |
| ポスター候補 | 毎週日曜 05:00（14:00） | Wikimedia Commonsからライセンス確認済み画像を検索 |

Supabase CronからEdge Functionsを呼び出す。同期トークンの平文はSupabase Vaultに保管し、DB側にはハッシュを保存する。GitHubのソースコードにはトークンを含めない。

## データソースと利用条件

### Wikidata
- 構造化データはCC0。
- 作品候補、別名、公式URL、話数、制作会社、スタッフ、ジャンル、シリーズ、キャラクター、声優等の識別情報・関係を取得。
- あらすじ、紹介文、人物紹介などの文章は取り込まない。
- 出典のない値を推定して埋めない。

### Wikimedia Commons
- ポスター画像候補に限定。
- ファイルごとのライセンスを確認する。CC0／パブリックドメイン、CC BY、CC BY-SAのうち、必要なライセンス情報と帰属表示を取得できるものだけを対象とする。
- 非商用限定、改変禁止、フェアユース、全権利留保、ライセンス不明、作者・クレジット不明（表示が必要な場合）のファイルは除外。
- 画像URL、説明ページURL、ライセンスURL、作者・クレジットを保存する。

### 利用保留中
- Annictは利用条件の再確認が終わるまで無効。
- TMDB APIキーは利用しない。
- 新しいデータソースは、規約・再配布条件・料金・帰属表示を確認し、承認後にのみ有効化する。

## 収録対象と処理

### 1. 作品候補
Wikidataから日本作品の候補を取得する。候補は必ず `is_published=false` で保存する。タイトル・形式・年・日本作品としての同一性・収録方針を管理者が確認してから公開する。

### 2. 公開済み作品の拡充
外部IDで作品を照合し、次の情報を取得できる範囲で追加する。

| データ | Wikidataプロパティ |
|---|---|
| 公式サイト | P856 |
| 話数 | P1113 |
| 制作会社 | P272 |
| 監督 | P57 |
| 脚本 | P58 |
| プロデューサー | P162 |
| 作曲 | P86 |
| ジャンル | P136 |
| シリーズ | P179 |
| 前作・次作 | P155 / P156 |
| キャラクターの登場作品 | P1441 |
| キャラクターの声優 | P725 |
| MyAnimeList外部ID | P4086 |

制作会社はWikidataの分類情報も確認し、アニメーションスタジオと一般の制作会社を区別する。製作委員会や放送局をアニメーション制作会社として誤登録しない。

既存の手入力値は上書きしない。作品の公開状態も変更しない。

### 3. 重複防止
- Wikidata QIDと外部IDの一意性を利用。
- 同じ作品・人物・キャラクター・制作会社・ジャンルを複数作成しない。
- 関係レコードを追加する前に既存関係を確認。
- 作品の続編・前日譚・シリーズ関係は、出典で確認できる場合だけ登録。

### 4. エピソード・画像
- エピソードは各話単位の構造化データがある場合だけ候補登録する。作品の総話数から各話タイトルを推定しない。
- ポスターはライセンス確認ができる画像だけを登録する。候補が見つからない場合は空欄のままにする。

## 公開・審査ルール

- 新規作品は自動公開しない。
- 新規候補は管理者の審査待ちにする。
- 既存公開作品の追加情報は、外部IDが一致し、対象フィールドが空欄の場合に限って補完する。
- 収録範囲・作品同一性・出典が不明確な情報は保留する。
- 公開RLSは公開作品に関連する人物・キャラクター・制作会社等だけを一般公開する。非公開候補だけに紐付く関連データは一般ユーザーに表示しない。

## 監視・今後の改善

- 各同期の開始・成功・失敗を `catalog_sync_runs` に記録。
- Commons画像は `catalog_sync_state` のオフセットで小分けに処理する。
- Wikidataの候補収集もページ位置を保存し、毎日少しずつ範囲を進める。
- 次の改善候補：候補審査画面での一括確認、同期失敗の通知、各フィールドの最終確認日時表示、公式一次資料との追加照合。

このシステムは、承認済みソースが提供する構造化データを自動的に補完する。すべての作品・全話・全スタッフの情報が必ず取得できるわけではない。
