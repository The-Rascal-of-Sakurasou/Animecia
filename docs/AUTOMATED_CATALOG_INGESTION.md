# ANIXIA 自動カタログ収録システム

更新日：2026-11-18

## 目的

承認済みデータソースから作品・人物・キャラクター・制作会社・ジャンル・各話等の構造化情報を定期取得し、Supabaseへ重複を避けて反映する。情報源に存在しない値は推測で作らない。

## 自動実行スケジュール

時刻はUTC（日本時間）。

| 処理 | スケジュール | 内容 |
|---|---|---|
| 作品カタログ同期 | 毎日 02:30（11:30） | Wikidataの作品候補を取得 |
| 作品メタデータ拡充 | 毎日 03:15（12:15） | 公開作品の別名・公式URL・話数・スタッフ・ジャンル等を補完 |
| 放送季節同期 | 毎日 03:35（12:35） | 現行シーズン作品を照合し、未登録候補を追加 |
| エピソード同期 | 毎日 04:00（13:00） | Wikidataにある各話データを取得 |
| ポスター候補同期 | 毎週日曜 05:00（14:00） | Wikimedia CommonsのPD/CC0画像のみ検索 |

同期はSupabase CronとEdge Functionsで実行する。同期トークンはSupabase Vaultで管理し、GitHubには平文を置かない。

## 利用データソース

### Wikidata
- 構造化データはCC0。作品名、別名、公開年、形式、公式URL、話数、制作会社、スタッフ、ジャンル、シリーズ、キャラクター、声優、外部ID等を取得する。
- 文章のあらすじ・紹介文はコピーしない。
- 公式情報とWikidataの記録が食い違う場合は、値を断定せず保留する。

### Wikimedia Commons
- 画像はファイル単位でライセンスを確認する。
- 現在はパブリックドメインまたはCC0と確認できるものだけを許可する。
- CC BY、CC BY-SA等の著作権付きライセンス、ライセンス不明、帰属表示を確認できない画像は採用しない。
- 現時点で採用済みポスターは0件。

### 無効化したソース
- 日本語Wikipediaの本文・あらすじ取り込みは停止。本文のコピーは行わず、現在の登録件数は0件。
- Annictは利用条件の確認が終わるまで無効。
- TMDB APIキーは使用しない。

## 公開判定

- 新規候補は自動収集する。
- 公開条件を満たさない候補は非公開のまま残す。
- 自動公開の対象は、日本作品としての識別子・日本語タイトル・公開年・対応形式などの条件を満たすものに限定する。
- 作品の同一性や収録範囲が曖昧な場合は自動公開しない。
- エピソード情報も作品本編とは別に確認し、各話タイトルを推測しない。

## 監視と制限

- 同期開始・成功・失敗・取得件数は `catalog_sync_runs` に記録。
- Wikidataの候補取得・メタデータ拡充・季節同期は小分けにして実行。
- 出典が存在しないデータは追加しない。
- データソースの利用条件が変わった場合は、承認状態を無効にして同期を停止する。
- 外部APIの有料キーは利用していない。Supabaseの実行回数・通信量は契約プランの上限に従う。
