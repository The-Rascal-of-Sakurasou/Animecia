# ANIXIA

**ANIXIA** は、日本語で使いやすいアニメ総合プラットフォームです。

作品データベースを中心に、検索・おすすめ診断・クイズ・ランキング・視聴管理・レビュー・ユーザー機能を一体化し、作品データベースを中心に、情報を探しやすく整理したサービスを目指します。

## UI / デザイン方針

- 対応言語：日本語・英語
- 日本語を主軸に、英語へ切り替え可能なインターフェース
- MyAnimeListを情報設計の参考にしつつ、画面表現はANIXIA独自に設計
- キャッチコピーを設けず、検索・作品情報・ランキングなどの機能を中心に構成
- PC・タブレット・スマートフォンに対応

## 主な機能領域

- **アニメデータベース**：日本語タイトル、別名、英語名、ローマ字、あらすじ、形式、放送時期、話数、画像、ジャンル、制作会社、人物・キャラクター情報
- **検索・発見**：タイトル検索、五十音順、ジャンル・年代・クール・形式・制作会社などの絞り込み
- **作品詳細**：作品情報、関連作品、人物・キャラクター、評価、レビュー
- **視聴管理**：お気に入り、視聴予定、視聴中、視聴済み、中断、話数進捗
- **おすすめ診断**：AIを使わず、回答と条件・重み付けによって候補作品を提示
- **クイズ**：作品知識クイズ、難易度、回答履歴、スコア
- **ランキング・比較**：評価、人気、レビュー、シーズン別ランキング、複数作品比較
- **ユーザー機能**：アカウント、プロフィール、個人評価、レビュー、実績
- **管理機能**：作品・ジャンル・制作会社・クイズ・レビュー・おすすめ枠などの管理

## データソース方針

- 初期作品データ：Wikidataの構造化データ（CC0）。作品名・別名・日付・話数・識別子等に限定し、画像やあらすじ本文は取り込まない。\n- しょぼいカレンダー：タイトルの一意な完全一致照合、読み仮名・略称・英題の補完に利用。画像やあらすじ本文は取り込まない。
- 追加候補：Annict API。2026-11-25施行予定の規約を確認後に利用可否を判断する。
- Jikan / TMDB：利用条件・再配布・商用利用条件の確認が完了するまで未採用。
- AniList：競合サービス利用・大量収集の制限があるため採用しない。

データの出典・利用条件・登録状況は [データソース方針](docs/DATA_SOURCES.md) を参照してください。

## セキュリティ方針

- Supabase Authによるアカウント管理
- ユーザー固有データはRow Level Security（RLS）で本人に限定
- 管理者権限を一般ユーザーから分離
- クイズの正解データは公開APIから分離し、サーバー側で採点
- 公開クライアントにはpublishable keyのみを使用し、service role keyを含めない

## 開発原則

1. 旧サイトのデータを不用意に削除・変更しない。
2. 新ANIXIAのDBと画面を段階的に接続し、旧DBへの参照を残さない状態を目指す。
3. 既存機能を再実装する前に、テーブル・RLS・画面の実装状況を照合する。
4. 画面・データ・権限を一体でテストし、未検証機能を完成扱いにしない。
5. 外部API・画像・文章の利用条件を確認する。
6. 月額0円を目標とし、無料枠の上限と将来の費用発生条件を監視する。
